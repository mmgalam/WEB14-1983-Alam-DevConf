# 🚀 DevConf 2026

A modern and responsive developer conference website built for **DevConf 2026**.

The website presents a developer conference with speaker information, conference packages, pricing, workshops, networking opportunities, and a 48-hour hackathon.

🔗 **Live Website:** https://mmgalam.github.io/WEB14-1983-Alam-DevConf/

---

## 📌 Project Overview

**DevConf 2026** is a developer conference landing page designed for developers, engineers, founders, and tech enthusiasts.

The website includes:

* 🎤 Conference speakers
* 💳 Conference pricing plans
* 🧑‍💻 Workshops and technical talks
* 🤝 Networking opportunities
* ⚡ DevConf Hackathon 2026
* 🤖 AI-focused development themes
* 📱 Responsive and modern UI

---

## ✨ Features

### 🎤 Speaker Section

Showcases conference speakers and their technology areas such as:

* AI / ML
* Cloud & DevOps
* Frontend
* Security

### 💰 Pricing Section

Includes three conference packages:

* Standard
* Pro
* Team

Each package provides different conference benefits and features.

### ⚡ Hackathon Section

Features the **DevConf Hackathon 2026** with:

* AI for Modern Web theme
* 48-hour coding challenge
* Team size of 2–4 members
* Different project concepts
